# 本地聊天网页
(this repo is 100%ai generated including the readme :)        )
一个**单文件、零依赖**的聊天界面。Python 标准库 + 一个 HTML 页面，双击运行即可，
把自己的 API 地址和 Key 填进去就能对话。

> 本仓库不含任何 API Key，也不含任何第三方中转站地址——只有一个手填入口。
>你可以直接 fork，不必担心把凭据泄露出去。

---

## 为什么会有这个

市面上的中转站说没就没。这个项目的定位是：**把 UI 和配置权拿回自己手里**，
API 地址随时可换，对话记录存在自己硬盘上，不看任何人的脸色。

## 快速开始

```bash
python chat.py                 # 打开 http://127.0.0.1:8788
python chat.py --port 9000     # 换端口
python chat.py --open          # 顺手打开浏览器
```

Windows 用户也可以直接双击 `start_chat.bat`。

**要求**：Python 3.8+，无第三方依赖。只有接 Anthropic 协议的站才需要额外装 `anthropic`
（`pip install anthropic`）；读 PDF 附件时会从公开 CDN 拉取 pdf.js，需要联网。

## 第一次使用

页面打开后，看**中间那栏「模型配置」**：

1. 展开 **服务商** → 填 **地址** 和 **Key**
   - OpenAI 兼容：`https://api.example.com/v1`
   - Anthropic 协议：改 `chat.py` 里 `PROVIDERS` 的 `protocol` 为 `"anthropic"`，地址填不带 `/v1` 的根
2. 点 **拉取模型列表** → 从下拉框选一个模型
3. 点 **保存**（配置存在浏览器 localStorage，换台机器要重新填）

底部有一排「可用性」指示灯，点 **重新检测** 会真实打一次小请求验证对面能不能聊。

## 界面

三栏，左侧和中间的栏可以用标题栏的两个按钮折叠。

| 栏位 | 内容 |
|---|---|
| 对话历史 | 本机存档的会话列表，可进入 / 删除 / 新建 |
| 模型配置 | 服务商、模型、角色设定、调参、图片地址、流式开关、保存与导入 |
| AI 对话 | 消息区 + 输入框 |

## 参数说明

| 参数 | 作用 | 默认 |
|---|---|---|
| Temperature | 控制随机性与创造性 | 0.70 |
| Top P | 核采样，控制词汇多样性 | 1.00 |
| Frequency Penalty | 频率惩罚，减少重复词 | 0.00 |
| Presence Penalty | 存在惩罚，鼓励新话题 | 0.00 |
| Max Tokens | 单次生成上限 | 4096 |
| Seed | 随机种子，填了更易复现结果 | 留空随机 |
| 图片地址 | 开启后随请求下发图片 URL，做多模态对话 | 关 |
| 流式输出 | 关闭后等整段生成完再一次性显示 | 开 |

`top_k` 和「停止词」藏在「其它参数」里——不少上游并不支持这两项。

## 消息能做什么

每条 AI 回答和提问下面都有一行小按钮：

- **重新生成** ——在原位置生成一条新的分支，旧的不丢
- **编辑**（提问） ——改完会长出新分支，原文保留
- **复制** / **删除** ——删除会把该分支及其子树一起摘掉
- 同一层有多个分支时，会出现 `‹ 2/3 ›` 这样的切换箭头

顶部还有**导出对话**（Markdown / JSON / 纯文本）和**停止生成**。

## 隐私

- API 地址和 Key 存在你浏览器的 localStorage 里，**不会**进版本库
- 服务端日志只记模型名、温度、轮数，**不记**地址与 Key
- 页面源码里查不到任何凭据：服务端只向前端下发 `hasKey` 这样的布尔标记，真正的 Key 由服务端自己取用
- 对话记录存本机 `chat_history/*.json`，是**明文**，已被 `.gitignore` 忽略

## 已知限制

- **输出原样排版**（保留换行与空格），不渲染 Markdown 语法成富文本；导出的 Markdown 文件是原始文本
- 上游对 `max_tokens` 和停止词的支持参差不齐，有些站会直接忽略
- 图片走的是 URL 方式的真多模态；附件上传做的是文本提取（含 PDF），**不是**把本地图片发给模型看图
- 出错会直接把错误显示出来，**不会**自动换其他服务商（这个行为是有意保留的：静默切换会让人搞不清到底是谁在回答）
- 单进程、单用户自用，没有鉴权，别直接暴露到公网

## 常见问题

**启动后页面还是旧的**
Windows 上端口可以被重复绑定（`SO_REUSEADDR` 语义不同于 Linux），新进程起来了但请求仍打到旧进程。
用 `netstat -ano | findstr :8788` 查出 PID 再 `taskkill /PID <PID> /F`，然后重启。

**401 Unauthorized**
Key 填错或已失效。先在可用性面板点「重新检测」确认。

**429 Too Many Requests**
对面限流（TPM / RPM 上限），不是配置错误，等一会儿或换额度更大的 Key。

**一直提示「没填 API 地址」或连不上**
确认地址该不该带 `/v1`：OpenAI 兼容站通常要带，Anthropic 协议站不带。
程序只会在「地址完全没有路径」时自动补 `/v1`。
